
# Sales Data Analysis 

## Objective
Analyze and visualize sales data to understand product performance, regional distribution, and sales trends over time.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
- Columns: Date, Product, Region, Sales
- Sample: 10-50 rows (can be expanded)

## Features / Visualizations
- Total, highest, and lowest sales
- Sales by Product (Bar chart)
- Sales by Region (Pie chart)
- Sales Trend over Time (Line chart)
